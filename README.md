# Cybersecurity Attack Analysis — Advanced Excel

## Project Overview
This project analyzes global cybersecurity threats from 2015 to 2024 using Microsoft Excel to identify attack patterns, financial losses, affected users, and resolution times.

## Objectives
- Analyze different types of cyberattacks.
- Examine financial losses and affected users.
- Compare cybersecurity threats across countries and industries.
- Identify trends in attack types and resolution times.
- Present key findings through an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Formulas
- Data Cleaning
- KPI Cards and Interactive Dashboards

## Project Work
- Cleaned and organized the cybersecurity dataset.
- Analyzed attack patterns and financial losses.
- Created PivotTables and PivotCharts to summarize key metrics.
- Developed an interactive dashboard to visualize important findings.

## Key Findings
- Identified common cyberattack types and their distribution.
- Examined financial losses associated with cyberattacks.
- Compared affected users and resolution times.
- Explored differences in cybersecurity threats across countries and industries.
